# Local reference host — Walkthroughs

These scope decisions derive from the eleven accepted roadmap recommendations
dated 2026-09-13. Technical design review is not represented as new user approval.

## Q1 — Must every customer use a trusted service?

> **Status:** LOCKED 2026-09-13 — local core remains independently useful.

No mandatory cloud or host service. Deliver one optional named reference host
alongside portable advisory examples. This preserves local CLI use while making
an actual hard-delivery integration possible. A mandatory-service requirement
would need a new product decision. Folded into SPEC A1 and build phases 1–5.

## Q2 — What makes the hard gate different from prompting?

> **Status:** LOCKED 2026-09-13 — delivery authority is independently controlled.

The candidate must not control judge, policy, evidence or delivery storage.
Prompt instructions alone earn no enforcement credit. Actual refusal and
legitimate-operation transcripts are required for each advertised host profile.
Docker is a reversible implementation selection based on available local runtime,
not a user-selected vendor dependency. Folded into SPEC A1/A4/A5 and H01–H08.

## Q3 — Can incomplete construction be checkpointed?

> **Status:** LOCKED 2026-09-13 — legitimate proper-subset progress is allowed.

Permit the established full-gate unmet progress rule without presenting skipped
metrics as checked. Progress permission does not authorize delivery. Final
delivery requires fresh full green for the exact frozen work. Folded into A3/A5.

## Q4 — Does green implicitly accept a pin?

> **Status:** LOCKED 2026-09-13 — acceptance remains a trusted operator action.

Preserve met-but-unaccepted observations. Use reviewed preview/exact-digest
acceptance separately, with persistent provenance. Optional signing belongs to
B12, not implicit automatic acceptance in B07. Folded into A3 and H04.

## Q5 — What platform and extension claims are required?

> **Status:** LOCKED 2026-09-13 — execute named-platform evidence before claims.

macOS/Linux precede Windows/non-POSIX. The first named host uses a pinned local
Linux container profile; no other platform is certified by inference. Signing,
held-out evaluation, services, stronger containment and hosted extensions remain
required later roadmap slices, not silently removed. Folded into H07 and DEFERRED.

## Q6 — What actions need another approval?

> **Status:** LOCKED 2026-09-13 — isolated branch commits/pushes only on green.

Ask before merging, publishing, deploying, replacing the installed judge or
spending. Existing hardware and included allowances may be used. Preserve review
gaps honestly; do not retry a service-blocked review through a bypass route.
Folded into build stop-lines. No new spending follows from the technical design.
